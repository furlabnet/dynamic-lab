# @furlab/the-lab-sans

The Lab Sans, the Furlab typeface: 8 weights (Thin 100 to Black 900), each with an italic, as
OpenType files and a stylesheet of `@font-face` rules.

```ts
import '@furlab/the-lab-sans'
```

Dynamic Lab lists `'The Lab Sans'` first in `--font-sans` and `--font-display`, so once this
stylesheet is loaded the components use it with no further setup.

The package is private to this repository and isn't published.
